## Из аудита клиентов (22.09.2026)
- **Desktop TUN-режим.** Весь трафик через TUN (xray tun / sing-box) с правами администратора на macOS/Windows: kill switch, покрытие приложений, которые игнорируют системный прокси (CLI, игры, UDP/WebRTC). Сейчас Desktop работает только в режиме системного прокси.
- **P2P между двумя реальными телефонами.** Проверено: Android-клиент ↔ пир на хосте, и сигналинг/ICE между двумя эмуляторами (связность там упирается в QEMU-NAT). Прогнать Android ↔ Android на реальных устройствах в разных сетях.
- **К вопросу про пинг до нод:** это дёшево. Сейчас пинг показывается для выбранного региона, хост берётся из уже полученных ссылок, без отдельных запросов к серверу. Для всего списка можно мерить так же — при открытии пикера и только пока VPN выключен (через туннель цифра бессмысленна).
